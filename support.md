# MenuDock Support

MenuDock is a macOS menu bar utility for launching and switching
between applications.

- Screenshots, if helpful, with personal information hidden

## Frequently Asked Questions

### How do I add an application?

Right-click any application icon managed by MenuDock and choose
“Add Application…”.

If the application list is empty, you can add applications
from the settings window.

### Why is there no MenuDock icon in the Dock?

MenuDock runs in the menu bar and does not display a Dock icon.
Opening MenuDock again opens its settings window.

### How do I remove an application?

Remove its entry from the application list in Settings.

This does not uninstall or quit the application.

### What should I do if an application will not launch?

Confirm that the application is still installed on your Mac
and can be opened normally from Finder.

If it has been moved or reinstalled, remove its old entry
from MenuDock and add it again.

### How do I quit MenuDock?

Right-click any application icon managed by MenuDock
and choose “Quit MenuDock”.
